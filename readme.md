# 🎮 Adaptive Rock Paper Scissors

An intelligent Rock–Paper–Scissors game where the computer **learns from your behavior**.

Instead of random moves, the computer:
- Tracks your past choices
- Predicts your most frequent move
- Plays the counter strategy

---

## 🚀 Features
- Adaptive decision-making
- Frequency-based prediction
- Clean CLI interface
- No third-party dependencies
